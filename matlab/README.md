# Smart Krishi (Uzhavan AI) - MATLAB Crop Health Engine

The **MATLAB Crop Health Engine** provides deep transfer learning, classical leaf segmentation, explainable AI (Grad-CAM), and irrigation simulation for the Smart Krishi platform.

---

## 📁 Project Directory Structure

```text
matlab/
├── dataset/
│   └── tomato/
│       ├── Healthy/              # Store real tomato healthy leaf images (.jpg, .png)
│       ├── Early_Blight/         # Store real tomato early blight leaf images (.jpg, .png)
│       └── Late_Blight/          # Store real tomato late blight leaf images (.jpg, .png)
├── models/
│   └── uzhavanNet.mat            # Saved trained network weights and metadata (generated by trainModel)

│   ├── panel.png                 # 6-panel diagnostic visualization
│   ├── confusion_matrix.png      # Test split confusion matrix
│   ├── training_curves.png       # Loss and accuracy curves

│   └── testSplit.mat             # Held-out test split files and labels

├── batchPredict.m                # Batch inference across an entire folder of photos
├── evaluateModel.m               # Held-out test evaluation, confusion matrix, and latency
├── generateGradCAM.m             # Grad-CAM attention heatmap generation

```

## 🚀 Quick Start Guide

### Step 1: Open MATLAB and Navigate to Folder
In MATLAB Command Window or terminal:
```matlab
cd('c:/smart-krishi/matlab');
addpath(pwd);
```

### Step 2: Run Setup Check
Run the setup diagnostic script to verify dependencies, toolboxes, and folder structure:
```matlab
setup_check
```
`setup_check` validates:
- MATLAB release and core deep learning functions (`trainnet`, `imagePretrainedNetwork`, etc.)
- Toolboxes and ResNet-18 support package
- Required directory paths (`dataset/tomato/Healthy`, `dataset/tomato/Early_Blight`, `dataset/tomato/Late_Blight`, `models/`, `results/`)
- Number of images found in each class folder
- Presence of trained `models/uzhavanNet.mat`

### Step 3: Populate Dataset with Real Images
Copy tomato leaf images into their respective folders:
- `dataset/tomato/Healthy/`
- `dataset/tomato/Early_Blight/`
- `dataset/tomato/Late_Blight/`

> **Note**:
> - `trainModel.m` requires at least 2 classes and a minimum of 10 total images to run.
> - For balanced training, 100–350 images per class are recommended. Subsampling is managed via `cfg.maxImagesPerClass` in `uzhavanConfig.m`.

## 🔬 Execution Instructions

### 1. Model Training
Once real images are placed in the dataset folders, start model training:
```matlab
trainModel
```
- Trains a transfer learning model based on ResNet-18 with data augmentation (rotation, reflections, scale, translations).
- Splits data: 70% Training, 15% Validation, 15% Test.
- Saves the trained model to `models/uzhavanNet.mat`.
- Saves test partition to `results/testSplit.mat` and training plots to `results/training_curves.png`.

### 2. Model Evaluation
Evaluate the trained model on the held-out test split:
```matlab
M = evaluateModel
```
- Calculates per-class Precision, Recall, F1-Score, Overall Accuracy, and median inference latency.
- Generates and exports `results/confusion_matrix.png` and saves metrics to `results/metrics.mat`.

### 3. Single Image Disease Diagnosis
To diagnose a single crop leaf image:
```matlab
res = predictDisease('path/to/leaf_image.jpg');
disp(res);
```
- Pipeline runs:
  1. Quality gating (`assessImageQuality.m`: checks blur, darkness, glare, and leaf fraction).
  2. Classical segmentation (`segmentLeaf.m`: measures visible lesion fraction).
  3. CNN inference (`runNet.m`: softmax probabilities).
  4. Confidence check (`cfg.minConfidence = 0.70`, `cfg.minMargin = 0.20`).
  5. Explainability (`generateGradCAM.m`: visual attention heatmap).
  6. Leaf Health Index calculation (`healthScore.m`: 0–100 score and risk band).
- Saves full diagnostic figure to `results/panel.png`.

### 4. Batch Prediction
Run inference across an entire folder of photos:
```matlab
T = batchPredict('path/to/folder_with_images');
```
Outputs a summary table and exports `results/batch_predictions.csv`.

### 5. Irrigation Simulation (FAO-56 Soil-Water Bucket)
Run the soil water balance simulation under various climate scenarios:
```matlab
simulateIrrigation;                         % Baseline schedule
simulateIrrigation('irrigMult', 0.8);        % Scenario: -20% irrigation
simulateIrrigation('rainMult', 1.5);         % Scenario: +50% rainfall
```

### 6. Full End-to-End Run
Run the sections sequentially from `main.m`:
```matlab
main
```

## ⚙️ Configuration & Threshold Tuning

All hyperparameters and gating thresholds are centralized in `uzhavanConfig.m`:
- `cfg.inputSize`: CNN input dimensions `[224 224 3]`.
- `cfg.backbone`: Backbone architecture (`"resnet18"`).
- `cfg.epochs`: Number of training epochs (default `4`).
- `cfg.miniBatch`: Batch size (default `32`).
- `cfg.learningRate`: Adam learning rate (default `1e-4`).
- `cfg.minConfidence`: Confidence rejection threshold (default `0.70`).
- `cfg.minMargin`: Margin between top-1 and top-2 class (default `0.20`).
- `cfg.blurThreshold`: Laplacian variance threshold for motion blur detection (default `40`).
- `cfg.minBrightness` / `cfg.maxBrightness`: Illumination thresholds (default `0.15` - `0.92`).
- `cfg.minLeafFraction`: Minimum foreground leaf area fraction in frame (default `0.10`).
